## المزايا المنفذة والجاهزة للتشغيل الفوري

1. **اللعب المحلي الكامل ضد الكمبيوتر (بدون إنترنت أو API)**:
   - من 3 إلى 8 لاعبين حول طاولة الاستراحة.
   - المرشد والخصم الرئيسي **«أبو فهد»** مع 6 خصوم سعوديين آخرين.
   - 3 مستويات صعوبة (**سهل، متوسط، صعب**) مع ذاكرة قانونية للخصوم الآليين دون أي اطلاع على بطاقاتك المخفية أو البطاقة المقلوبة.
2. **الجولة التعليمية التفاعلية مع «أبو فهد»**:
   - تعمل تلقائيًا عند أول تشغيل (مع إمكانية تخطيها فورًا أو إعادتها من القائمة الرئيسية في أي وقت).
   - تشمل 6 خطوات تفاعلية محددة مسبقًا لشرح البطاقات، اللعب بالصدق، الخداع، زر «صادوه!»، عقوبة التحدي، وتجربة الفوز القانوني.
3. **تنفيذ كامل ودقيق لقواعد اللعب والحالات الخاصة**:
   - الشخصيات الست (**الملقوف، النشّال، السند، المصرّف، المخبّص، الكبير**) مع وصف القدرة في سطر عربي واضح داخل كل بطاقة.
   - عداد 15 ثانية لاختيار الحركة (مع تنفيذ حركة قانونية تلقائية عند انتهاء الوقت) وعداد 5 ثوانٍ لتحدي «صادوه!».
   - معالجة كاملة للحالات الخاصة الـ11 (منع الفوز بالبطاقة الإضافية للمصرّف، عدم الفوز خارج الدور عند إفراغ اليد بالنشّال، إعادة خلط البطاقات المستخدمة عند نفاد كومة السحب، درع السند التلقائي، وغيرها).
4. **واجهات الغرف الجماعية والشات العام**:
   - واجهات إنشاء غرفة، الانضمام برمز أو رابط دعوة، الغرف المختلطة (بشر + آليين)، مؤشرات الاتصال والانقطاع، وواجهة العودة إلى المباراة بعد الانقطاع.
   - شات عام مع فقاعات رسائل تظهر فوق مقعد اللاعب لمدة 4 ثوانٍ، ردود فعل سريعة بلهجة سعودية، منع الروابط والصور، وأزرار الكتم والإبلاغ عن الإساءة.
5. **الـ 12 أصلًا رسوميًا مفصولة وجاهزة في `public/assets/`**:
   - `malqoof.png`, `nashal.png`, `sanad.png`, `mosarref.png`, `mokhabbes.png`, `alkabeer.png`, `abu-fahad.png`, `logo.png`, `card-back.png`, `game-table.png`, `menu-background.png`, `card-frame.png`.

## متطلبات التشغيل محليًا (Development)

تأكد من وجود **Node.js 18+** ثم نفّذ الأوامر التالية داخل مجلد المشروع:

```bash
# 1. تثبيت الحزم
npm install

# 2. تشغيل خادم التطوير المحلي
npm run dev

# 3. تشغيل الاختبارات الآلية لمحرك اللعبة
npm run test:vitest
```

## بناء نسخة الإنتاج والنشر على GitHub Pages

تم ضبط إعدادات `vite.config.ts` باستخدام المسار النسبي (`base: process.env.VITE_BASE_PATH || './'`) بحيث تعمل اللعبة والصور وجميع الملفات تلقائيًا على **GitHub Pages** تحت أي اسم مستودع (`https://<username>.github.io/<repo-name>/`) دون الحاجة لمعرفة اسم المستودع مسبقًا.

### خطوات البناء المحلي:

```bash
npm run build
```

سينتج مجلد `dist/` جاهزًا بالكامل للاستضافة الثابتة (Static Hosting)، كما توجد نسخة إنتاج مبنية وجاهزة داخل `dist/` المرفق.

### خطوات النشر على GitHub Pages:

1. ارفع محتويات المشروع إلى مستودع GitHub جديد.
2. من إعدادات المستودع (**Settings -> Pages**)، اختر النشر عبر **GitHub Actions** أو من فرع `gh-pages` بعد تشغيل `npm run build`.
3. إذا أردت تحديد مسار فرعي مخصص أثناء البناء، يمكنك تمرير المتغير:
   ```bash
   VITE_BASE_PATH="/my-repo-name/" npm run build
   ```
